How OmShare Works

The Simple 3-Step Process

Step 1: Select a File

Choose any file from your device - PDFs, videos, documents, images, or anything else. There are no size limits. OmShare can handle files from kilobytes to gigabytes.

Step 2: Generate a Code

Click "Generate Code" to create a unique 6-digit code. Share this code with the recipient through any method - email, messaging, chat, or even verbally.

Step 3: Receiver Downloads

The recipient enters the 6-digit code, and the file begins transferring directly from your device to theirs. No server storage, no uploads to the cloud.

Technology Behind OmShare

Peer-to-Peer (P2P) Transfer

OmShare uses WebRTC technology to create a direct connection between two browsers. Your file travels directly from your computer to the recipient's computer - it never sits on a server.

No Sign-Up Required

There are no accounts, logins, or registrations. Just open the app and start sharing. Every transfer is anonymous and independent.

Secure & Encrypted

WebRTC connections are encrypted by default using DTLS (Datagram Transport Layer Security). Your files are protected during transfer.

Unlimited File Size

Send files of any size. OmShare handles everything from small text files to multi-gigabyte videos and databases.

What Happens to Your File?

  • ✓ File stays on your device until recipient connects
  • ✓ Transfer happens directly (device-to-device)
  • ✓ File is auto-deleted after download
  • ✓ No copies stored on servers
  • ✓ No backups or logs of file content

How Long Does Transfer Take?

Speed depends on your internet connection. OmShare is optimized for modern broadband speeds and can transfer files at rates of 1-10 Mbps depending on network conditions.

What About Codes?

Each 6-digit code is unique and expires after 24 hours. If no one connects, the code simply stops working. Codes are stored temporarily for signaling only - they don't contain any file data.

Maximum File Size?

OmShare has no hard limits. The only restriction is your device's available memory and your internet connection stability. Most users can transfer files up to 10GB+ without issues.

Browser Support

OmShare works in all modern browsers:

  • Chrome/Edge 76+
  • Firefox 68+
  • Safari 14.1+
  • Opera 63+
  • Any browser supporting WebRTC

Privacy & Security

OmShare is completely private. We don't store files, log activities, or track users. The code is the only connection between sender and receiver, and it expires automatically.
